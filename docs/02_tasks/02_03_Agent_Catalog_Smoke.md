# 02_03 Agent Catalog 实机烟测清单（M0.4 / 0.4.10）

在 InDesign 2024+ 加载本插件后逐项勾选。用于关闭 `99_07` / `88_02` 中与目录 Agent 相关的验证缺口。

## 前置

- [ ] 配置页自配 BYOK 可保存；对话能通模型  
- [ ] 打开含表样式的样例文档  

## 工艺顾问（default）

- [ ] 首屏自称工艺顾问，能给步骤而非空推诿  
- [ ] 建议伪表时出现「加载「伪表恢复」」chip，点选进入场景  

## 伪表恢复

- [ ] 锁选区 → 识图外发确认 → 出 draft  
- [ ] 选表样式可替换；Undo 可回退  
- [ ] 切到「贴表规范化」后，系统提示清除识别稿，且不会误 replace  

## 选区排版

- [ ] 选中正文框 →「读取选区」锁定  
- [ ] 「分析排版」出指令预览；非法 type 被拒且文档无变化  
- [ ] 「应用指令」后字号/样式可见变化；Undo 可回退  
- [ ] 离开场景后预览指令被清除  

## 贴表规范化

- [ ] 点选真表或单元格 →「规范化当前表」套上表样式  
- [ ] 下拉改样式只记录偏好，不触发伪表替换文案  

## 文稿比对

- [ ] 上传 txt/docx/xlsx；>8MB 被拒  
- [ ] 首次发送弹出对照稿外发确认；取消则不调模型  
- [ ] 「开始比对」能出增删改清单  
- [ ] 退出比对场景后对照稿被清除  

## 文章校对

- [ ] 「读取选区」锁定文字；「校对选区」出问题清单  
- [ ] 编组选区能抽到子框文字（或明确提示选文本框）  

## GREP 助手

- [ ] 口语要规则 → `propose_grep`；可复制查找式/替换式到剪贴板  
- [ ] 「写入段落样式」→ 回复 `写入「段样式」用「字符样式」` → 段落样式出现 Nested GREP  
- [ ] 缺样式名或不存在时提示失败且不误写
