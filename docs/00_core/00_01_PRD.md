# 00_01 Product Requirements

## Understanding Card

- **Target users:** 书籍 / 杂志内页设计师（首要：本人工作流）
- **Core problem:** 内页选区排版微调慢；样式与对象创建 / 套用重复劳动多
- **Urgent spike (M0-T):** 选中矢量伪表 → 视觉识别 → 预览确认 → 真表 + 已有表样式 + 表头/表尾行并替换
- **First-stage goal (M0):** 选中区域 → AI 建议 → 白名单指令落地；可建/套段落与字符样式
- **Primary workflow:** 在 InDesign 选中文本框或对象 → 面板发起分析/应用 → 文档变更可 Undo
- **Known constraints:** UXP 面板；先直连模型 API，后换统一后端；兼容 InDesign 2024+
- **High-risk surfaces:** 模型输出校验、API Key 本机存储、部分写入失败回滚、供应商协议差异
- **Architecture-affecting unknowns:** 见 [`88_02_Planning_Ledgers.md`](../88_planning/88_02_Planning_Ledgers.md) To Verify

## Goals

1. 辅助书刊内页**局部**精准布局控制，而非全书自动重排。
2. 以**版式评估与优化**为产品重心；M0 先打通「能安全改」，M1 补齐「可解释评估」。
3. 用标准化 JSON 做 UXP ↔ 模型（及未来后端）的数据桥梁，双向错误可反馈。
4. 多供应商可配置接入（Claude / ChatGPT / Gemini / DeepSeek / OpenAI 兼容中转）。

## Non-Goals (M0 / M0-T)

- 全书智能重排
- 个人知识库 / 对话式专属顾问
- 印前全局语义校对
- 表/单元格/图形样式的**全量自动生成**（M0-T **只套用已有** Table Style）
- 统一托管后端（仅预留协议与 Transport 切换点）
- 为单一排版风格定制独立 Agent
- 无选区的整页盲识别伪表

## Primary User Journey (M0-T, current priority)

1. 打开画册 `.indd`，选中矢量伪表组合。
2. 配置（或沿用）支持 vision 的供应商 URL / Key / Model。
3. 确认外发选区图像提示后，执行识别 → 预览表格 → 选择已有 Table Style → 替换。
4. 预检通过后写入真表并仅在成功后删除原矢量；可 Undo。

## Primary User Journey (M0 baseline)

1. 打开含内页的 `.indd`，选中一个或多个文本框 / 对象。
2. 在面板选择供应商、填写 Base URL / API Key / Model（可保存本机）。
3. 点击「分析并建议」或「应用建议」。
4. 面板打包选区 JSON，直连模型，解析为白名单指令列表。
5. 校验通过后按序执行；失败则停止后续指令并展示错误；成功操作支持 Undo。

## Acceptance Themes

| Theme | Observable success |
| --- | --- |
| Selection I/O | 能读出选区文本、样式名、几何边界并展示/导出 JSON；组对象有 bounds |
| Safe apply | 仅执行白名单指令；非法 JSON / 未知 command 不改文档 |
| Style assist | 能创建并应用至少 1 个段落样式与 1 个字符样式 |
| Table recovery (M0-T) | 伪表→真表；已有表样式；头/尾行；预检与删对象顺序正确 |
| Multi-provider | OpenAI 兼容中转 + 至少另一原生供应商（Claude 或 Gemini）跑通同一业务路径 |
| Error UX | 错误 URL/Key/超时/校验失败均有可读反馈；图像外发可取消 |

## Roles

| Role | Permissions |
| --- | --- |
| Designer (local) | 配置本机 API、发起分析/应用、查看错误与指令预览 |
| Future backend service | 不在 M0；将接管鉴权、配额、审计日志 |
