# 88_01 Roadmap (from development archive)

本路线图吸收原始「InDesign AI 插件开发档案」及历次补充，并按 2026-11 修订策略重排优先级。

## Strategy Revision

1. **弱化**全书自动重排期望；聚焦单页与局部精准控制。
2. **强化**标准化 JSON + 双向错误处理。
3. **突出**版式评估与优化为核心重心（评估深度主落在 M1）。
4. UI：**主控面板 + 分步配置**；复杂参数进折叠/向导。
5. 风格：统一架构 + 动态配置/提示词，不为单风格做独立 Agent。

## Capability Backlog → Milestone

| Capability | Milestone |
| --- | --- |
| 图层与文本解析（选区） | M0 |
| 白名单排版微调 | M0 |
| 字符/段落样式生成与套用 | M0 |
| 多供应商直连（含中转 URL） | M0 |
| 版式评估（重心、留白、层级） | M1 |
| 对象样式 / 表 / 单元格 / 图形样式 | M2 |
| 嵌入/链接图与 PDF 文字提取 | M2 |
| 智能校对与印前（跨分散文本框） | M2 |
| 本地目录素材读取与初稿落地 | M2 |
| 参考成熟插件能力由模型指挥脚本 | 贯穿；M0 先白名单子集 |
| 统一后端 API | M3 |
| 个人经验知识库 / 对话顾问 | M3 |

## Explicitly Deprioritized

- 全书自动布局 / 结构化全书重排作为近期目标
- 每风格独立 Agent
