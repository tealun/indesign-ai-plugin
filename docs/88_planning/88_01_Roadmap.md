# 88_01 Roadmap (from development archive)

本路线图吸收原始「InDesign AI 插件开发档案」及历次补充，并按 2026-11 修订策略重排优先级。

## Strategy Revision

1. **弱化**全书自动重排期望；聚焦单页与局部精准控制。
2. **强化**标准化 JSON + 双向错误处理。
3. **突出**版式评估与优化为核心重心（评估深度主落在 M1）。
4. UI：**主控面板 + 分步配置**；复杂参数进折叠/向导。
5. 风格：统一架构 + 动态配置/提示词；**产品场景**按专属 Agent 列表加载（非「每视觉风格一进程」）。
6. **不做**溢出巡检 / 缺图重链 Agent（宿主或其它软件已有提醒）。

## Explicitly Deprioritized

- 全书自动布局 / 结构化全书重排作为近期目标
- 每视觉风格独立 Agent 进程
- **溢出巡检 Agent、缺图/批量重链 Agent**（外部工具已覆盖）
